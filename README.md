# LiveWallpaper-Basic-Port
 
This is a port of the "Basic" Live Wallpaper package found in Android Honeycomb. I will work to add settings so the wallpapers can behave either like they did on Honeycomb or the later versions in the picker itself.

Coding policy:
AI is used to get the initial project to compile, as there is way too much legacy code to efficiently handle by hand. Once the project and all its components are confirmed working as intended, each component is rewritten from scratch by hand. All releases will, same as any other projects, only include human written code.

All temporary AI code is stored in the port/ directory which will be deprecated once the project reaches a release version
